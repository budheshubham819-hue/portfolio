BEFORE SUBMISSION:
1. Replace "Your Name" / "YourName" with your actual name.
2. Replace the profile.svg placeholder with your own suitable profile photo (keep the filename profile.svg only if using the supplied illustration; otherwise update the img src in index.html).
3. Update college name, branch, year, email, city, social profile URLs, skills and project descriptions.
4. The contact form uses mailto as a no-JavaScript demonstration. Change your.email@example.com in both the form action and email link. Submitting opens the visitor's default email application; a real server-backed form needs a backend service.
5. Open index.html in a browser and test every nav link and the contact form.

No JavaScript or external CSS framework is used. Google Fonts are loaded online; fallback fonts are included.
